# S2H 문의 API 연결 준비

현재 공개 홈페이지 API는 비활성화 상태입니다. 이 디렉터리는 Cloudflare Workers + D1로 별도 배포할 수 있도록 준비한 예시이며 아직 배포되지 않았습니다.

1. 운영사와 개인정보 처리 목적, 수집 항목, 보유 기간, 삭제 절차 및 외부 수탁·국외 처리 여부를 확정하고 개인정보처리방침을 업데이트합니다.
2. 승인된 Cloudflare 계정에 D1 데이터베이스를 생성하고 wrangler.example.toml을 wrangler.toml로 복사합니다. 실제 D1 ID 및 허용 웹사이트 Origin을 설정합니다. GitHub Pages Origin은 계정 전체에 적용되므로 실제 운영 도메인만 허용하는 것이 바람직합니다.
3. D1에 schema.sql을 적용하고, 32자 이상의 충분히 무작위인 관리자 접근 키를 Wrangler secret으로 등록합니다. 공개 저장소·브라우저 저장소에 키를 기록하지 마세요.
4. Worker를 배포하고 인증 없는 관리 조회가 401인지, 허용되지 않는 Origin 차단, 유효하지 않은 입력 거부, 정상 접수 후 실제 D1 저장과 인증된 조회가 되는지 테스트합니다. 테스트 개인정보는 즉시 삭제하세요.
5. 운영사 승인 후 assets/inquiry-api.js의 baseUrl을 실제 HTTPS API 주소로 설정하고 enabled를 true로 변경합니다. 사이트 페이지의 캐시 버전도 갱신합니다.
6. admin/index.html에서 관리자 접근 키를 입력해 조회합니다. 페이지를 새로고침하면 키가 삭제됩니다. 현재 조회 전용이며, 공동 계정 대신 개인별 인증·권한, 감사 기록, 삭제 및 보유기간 자동 관리가 운영 전 추가로 필요합니다.

실제 배포와 운영 승인 전에는 기존 이메일 접수 방식을 유지합니다. API는 개인정보를 로그에 출력하지 않으며 공개 조회를 허용하지 않습니다. 공용 폼의 속도 제한은 기본 방어이며 대규모 스팸 대응에는 추가 보호가 필요합니다.
